# Sample Run

## Desktop View

The StudyHub dashboard displays:

- Sidebar navigation
- Search bar
- Student profile
- Four statistic cards
- Upcoming tasks
- Motivational quote

## Responsive View

On smaller screens:

- The sidebar becomes a horizontal navigation area.
- Dashboard cards rearrange into fewer columns.
- Content sections stack vertically.
- The layout adapts to mobile screen widths.

## Technologies

HTML5 and CSS3 only. No JavaScript is used.
